# Expense Tracker | مدير المصاريف

A simple web application to manage daily expenses. 
تطبيق ويب بسيط لإدارة المصاريف اليومية.

## Features | المميزات
- Add new expenses | إضافة مصاريف جديدة.
- Delete expenses | حذف المصاريف.
- Calculate total automatically | حساب المجموع تلقائياً.
- Save data using localStorage | حفظ البيانات في المتصفح.

## Technologies | التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript

## What I Learned | ماذا تعلمت
- DOM Manipulation | التعامل مع عناصر الصفحة.
- Handling Events | التعامل مع الأحداث.
- Arrays and Objects | المصفوفات والكائنات.
- LocalStorage & JSON | حفظ واسترجاع البيانات.

## How to Run | كيفية التشغيل
Just open `index.html` in any browser. | قم بفتح ملف `index.html` في أي متصفح.
